# Nani test round content

This pack contains 12 categories with exactly 50 questions each (600 total).

Each category has a `questions.csv` file. Image files remain in the external `Nani Test Run` folder so the repository stays lightweight; their filenames match the CSV `filename` column.

The manifest records the source URL, kind, answer, and reuse note for every row. Entries marked `seeded` are suitable for local test play; verify third-party rights before redistribution.
